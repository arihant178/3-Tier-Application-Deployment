3-Tier Student Application Deployment on AWS (Using Ubuntu EC2 and AWS Console)
---------------------------------------------------------------------------------
3-Tier Setup:

Frontend (Nginx on Public EC2): Acts as a reverse proxy.

Application Server (Tomcat on Private EC2): Hosts the Java-based Student app.

Database (MySQL on RDS): Stores student data.
----------------------------------------------------------------------------------
Always check Nginx and Tomcat logs for debugging:

/var/log/nginx/error.log

/opt/tomcat/logs/catalina.out

Use curl or telnet to verify connectivity between layers.

Organize your nginx site config:

Place reverse proxy config in /etc/nginx/sites-available/

Symlink it to /etc/nginx/sites-enabled/

Ensure consistent folder structure in Tomcat:

The context /student/ must match both in deployment and in reverse proxy config

Step 5: Connect and Setup Servers

NGINX Setup on Ubuntu EC2

 apt update
 apt install nginx -y

SSH into Tomcat EC2 from Nginx EC2

 apt update
 apt install openjdk-11-jdk curl -y
 mkdir -p /opt/tomcat
cd /opt/tomcat
 wget https://archive.apache.org/dist/tomcat/tomcat-9/v9.0.90/bin/apache-tomcat-9.0.90.tar.gz
 tar -xzf apache-tomcat-9.0.90.tar.gz
cd apache-tomcat-9.0.90/webapps
 curl -O https://s3-us-west-2.amazonaws.com/studentapi-cit/student.war
cd ../lib
 curl -O https://s3-us-west-2.amazonaws.com/studentapi-cit/mysql-connector.jar

Edit context.xml

cd ../conf
 nano context.xml
# Add below line inside <Context> tag (around line 21)
<Resource name="jdbc/TestDB" auth="Container" type="javax.sql.DataSource"
               maxTotal="100" maxIdle="30" maxWaitMillis="10000"
               username="admin" password="Passwd123$" driverClassName="com.mysql.jdbc.Driver"
               url="jdbc:mysql://<RDS-ENDPOINT>:3306/studentapp"/>


Start Tomcat

cd ../bin
chmod +x catalina.sh
./catalina.sh start

Create DB & Table:


CREATE DATABASE studentapp;
USE studentapp;

CREATE TABLE IF NOT EXISTS students (
  student_id INT NOT NULL AUTO_INCREMENT,
  student_name VARCHAR(100) NOT NULL,
  student_addr VARCHAR(100) NOT NULL,
  student_age VARCHAR(3) NOT NULL,
  student_qual VARCHAR(20) NOT NULL,
  student_percent VARCHAR(10) NOT NULL,
  student_year_passed VARCHAR(10) NOT NULL,
  PRIMARY KEY (student_id)
);

SHOW TABLES;
EXIT;

step 7: nginx reverse proxy

nan0 /etc/nginx/sites-available/default

edit it 

location / {
    proxy_pass http://192.168.2.95:8080/student/;

    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
